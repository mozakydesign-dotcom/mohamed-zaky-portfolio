# Mohamed Zaky — Portfolio

Static site (HTML / CSS / JS), no build step.

- `index.html` — home page
- `project.html` — case study page (one template for every project)
- `js/projects.js` — **all projects and case study content** live here
- `css/styles.css` — design (colours and fonts are at the top)
- `js/home.js`, `js/project.js`, `js/common.js` — animations and behaviour
- `assets/` — images

Deployed on Vercel from the `main` branch.
